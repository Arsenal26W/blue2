# 아프리카 탐험 2 (아이폰용 웹 실행기)

1996년 판다 엔터테인먼트의 도스 게임 《非洲探險2》 한글판을 아이폰 Safari에서 실행하는 웹페이지입니다. 브라우저용 DOSBox(js-dos)로 돌아갑니다.

## 이 저장소에 들어 있는 것

`index.html`, `app.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`

게임 파일은 이 저장소에 올리지 마세요. GitHub Pages는 공개 사이트라서 누구나 받아갈 수 있게 됩니다. 게임 파일은 아이폰에서 직접 넣습니다.

## 설치 순서

1. GitHub에서 새 저장소를 만들고(Public), 위 6개 파일을 올립니다.
2. 저장소의 Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 Save를 누릅니다.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 열립니다.
4. 아이폰 Safari로 그 주소를 열고, 공유 버튼 → ‘홈 화면에 추가’를 누릅니다.
5. 홈 화면에 생긴 아이콘으로 엽니다. 여기서부터는 Safari가 아니라 이 앱에서 하세요. 홈 화면 앱은 Safari와 저장 공간이 따로입니다.
6. ‘게임 파일 넣기’를 누르고 `africa2-game.zip`을 고릅니다. zip 대신 게임 폴더의 파일을 전부 골라도 됩니다(.iso 포함).
7. ‘게임 시작’을 누르고 아이폰을 가로로 돌립니다.

처음 실행할 때는 실행기(js-dos)를 내려받아야 해서 인터넷이 필요합니다.

## 세이브

- 게임 안의 저장 기능으로 저장하면, 10초 안에 아이폰 저장 공간에 자동으로 보관됩니다. 오른쪽 ‘보관’ 버튼을 누르면 바로 보관합니다.
- 메뉴의 ‘처음 화면으로’를 누르면 보관한 뒤에 나갑니다.
- 가끔 ‘세이브 내보내기’로 `AFRICA2.SAV`를 ‘파일’ 앱에 백업해두세요. 앱을 지우거나 아이폰을 바꿀 때 ‘세이브 가져오기’로 되살릴 수 있습니다.

## 화면 버튼

| 버튼 | 하는 일 |
|---|---|
| ESC, 엔터, 공백 | 같은 이름의 키를 누릅니다 |
| 자판 | 아이폰 키보드를 띄워 글자를 입력합니다 |
| 보관 | 세이브를 지금 아이폰에 보관합니다 |
| 메뉴 | 세이브 내보내기, 터치 방식, 화면 질감, 나가기 |

## 잘 안 될 때

- 커서가 누른 곳과 어긋나면: 메뉴 → ‘터치 방식’을 ‘트랙패드’로 바꿔보세요. 화면을 문질러 커서를 옮기고 톡 쳐서 클릭합니다.
- 소리가 안 나면: 게임 화면을 한 번 누르고, 볼륨을 올려보세요.
- ‘시작하지 못했어요’가 나오면: 인터넷 연결을 확인하고 앱을 완전히 닫았다가 다시 여세요.
